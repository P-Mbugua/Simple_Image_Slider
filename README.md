# Interactive Image Slider

This is a simple and interactive image slider built using HTML, CSS, and JavaScript. The slider is designed to showcase images with captions and is fully responsive, making it suitable for all screen sizes. The slider supports auto-sliding functionality and allows navigation through dots.

## Features
- Full-screen image slider
- Responsive design for all screen sizes
- Caption overlay on each image
- Auto-slide functionality with 3-second intervals
- Dot navigation to switch between slides
- Clean and minimalistic design
